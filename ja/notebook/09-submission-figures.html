以下のコードで、論文の図ごとに雑誌投稿用のベクターPDFとプレビュー・プレプリント作成用の600 dpi PNGを作成します。コード欄を展開すると各手順を確認できます。主要図の入力、除外、GAM、予測用の格子点は解析の章と共通で、パネルの配置と文字の体裁を変更しています。図S1は再現用の章で保存した元の代表例と基準値補正を用います。PDFとPNGはページ内への埋め込みではなく、ダウンロードして確認できます。

図生成用ノートブック（QMD）をダウンロード

元のレイアウト（6種の行、形質の列、正方形の描画領域）を維持します。図1・2・3の幅はそれぞれ120、155、85.5 mmです。高さは正方形のパネル幅と余白から計算し、それぞれ約235、228、231 mmになります。178 mmを上限として図ごとに幅を調整することで、パネルを並べ替えずに過度な縦長を避けます。パネル文字と、種・形質・推定曲線の対応も維持しています。種名は斜体、縦軸ラベルは形質の列ごとに共通です。図S2は120 × 120 mmで、回帰式と統計量を元と同じ図内に配置します。文字はArialの9 ptを基準とし、目盛数字や凡例には8.55 pt、斜体の種名と回帰式の説明には8.1 ptを使います。PDF内の線と文字はベクター形式です。修正後の \(E_t A\) の値と単位を維持しています。

雑誌への提出時は、本文のDOCX/ODTには図の画像を入れず、図の説明文を本文末尾に残し、主図を1図ずつPDFで提出します。初回投稿でも別ファイル提出が認められています。補足資料は別の規定に従い、可能であれば図・説明文・表・論文タイトル・著者名を含む単一PDFにまとめます。

自身のプレビューやプレプリント用には、別の原稿にPNGを［挿入］→［画像］から挿入します。縦横比を固定し、Wordの画像圧縮を無効にしてください。PNGは上記の実寸で600 dpiです。図の説明文を収めるための縮小は可能ですが、拡大すると実効解像度が下がります。必要に応じて、図入り原稿を利用するプレプリントサービスに合ったPDFへ書き出します。

PDF内の線と文字はベクターなので、ページを大きくしても細部の情報量は増えません。PDFもPNGも原稿内の配置寸法で作成し、PDFの拡大処理や追加の出力用依存関係は使いません。ただし、最終掲載時の幅と文字サイズは重要です。規定では最大幅178 mm、文字8～12 ptが指定されています。提出前には、上記の実寸で文字・点・線の読みやすさを確認してください。公式投稿規定を参照してください。

引張剛性は E_t * A として計算します。A = thick * width.x は、E.x（MPa）に対応する試験機の寸法（mm）から得ます。EA の単位はN、曲げ剛性と引張剛性の比の単位はmm²です。

# Draw directly to PNG so device-dependent clipping matches the intended layout.
save_submission_png <- function(file, width, height, pointsize, draw, dpi = 600) {
  png(sub("\\.pdf$", ".png", file), width = width, height = height,
      units = "in", res = dpi, type = "cairo", family = "Arial",
      pointsize = pointsize, bg = "white")
  on.exit(dev.off(), add = TRUE)
  draw()
}

# Draw manuscript panels using the same GAM function as the analysis chapters.
plot_submission_panels <- function(data, species, metrics, labels, file,
                                   x = "water_content", tensile = FALSE,
                                   reference_lines = NULL, label_offsets = NULL) {
  width_mm <- switch(as.character(length(metrics)), "2" = 85.5, "3" = 120, "4" = 155)
  stopifnot(!is.null(width_mm))
  # Horizontal offsets from each column's left edge, as fractions of page width.
  if (is.null(label_offsets)) {
    label_offsets <- rep(if (length(metrics) == 2L) 4 / width_mm else 2.5 / width_mm,
                         length(metrics))
  }
  stopifnot(length(label_offsets) == length(metrics), all(is.finite(label_offsets)))
  # Keep the original species rows, trait columns, and square plotting regions.
  margins <- c(1.3, 3.1, 1.6, 0.3)
  if (length(metrics) == 2L) margins[2] <- 4
  line_mm <- 9 / 72 * 25.4 * 1.2
  panel_mm <- width_mm / length(metrics) - sum(margins[c(2, 4)]) * line_mm
  height_mm <- length(species) * (panel_mm + sum(margins[c(1, 3)]) * line_mm) +
    1.8 * line_mm
  panels <- matrix(seq_len(length(species) * length(metrics)), nrow = length(species))
  # Match the orange/blue appearance of the embedded manuscript figures.
  original_palette <- palette()
  manuscript_palette <- original_palette
  manuscript_palette[c(6, 7)] <- c("#2977B5", "#D7673B")
  palette(manuscript_palette)
  on.exit(palette(original_palette), add = TRUE)
  cairo_pdf(file, width = width_mm / 25.4, height = height_mm / 25.4,
            family = "Arial", pointsize = 9, bg = "white")
  on.exit(dev.off(), add = TRUE)
  draw <- function() {
    layout(panels)
    par(mar = margins, oma = c(1.8, 0, 0, 0), tcl = -0.2,
        pty = "s", cex = 1, lwd = 0.5, fg = "black", col.axis = "black")
    results <- list()
    plot_regions <- list()
    for (j in seq_along(metrics)) {
      for (i in seq_along(species)) {
        subset_data <- data[data$spp == species[i], ]
        sides <- if (tensile) "tensile" else c("adaxial", "abaxial")
        ylim <- if (tensile) NULL else
          gam_ci_ylim(subset_data, x, metrics[j], c(60, 100))
        for (side in sides) {
          side_data <- if (tensile) subset_data else
            droplevels(subset(subset_data, leaf_side == side))
          results[[length(results) + 1L]] <- plot_gam_ci(
            data = side_data, x = x, y = metrics[j], side = side,
            pred_range = c(60, 100), xlim = c(100, 60), ylim = ylim, mar = margins,
            add = side == "abaxial", pch = if (side == "abaxial") 22 else 21,
            cex_pt = 0.75, pt_border_alpha = 0.5, line_lwd = 1.2,
            cex.axis = 0.95, cex.lab = 1, axis_lwd = 0.5, xaxt = "n",
            ci_lty = 3, mgp_x = c(1.7, 0.4, 0), mgp_y = c(2.5, 0.3, 0))
          if (!is.null(reference_lines) && metrics[j] == "E_ratio") {
            abline(h = reference_lines, lty = 2, lwd = 0.7)
          }
        }
        axis(1, at = seq(100, 60, -10), cex.axis = 0.95, gap.axis = 0.5,
             mgp = c(1.7, 0.4, 0), lwd = 0.5, lwd.ticks = 0.5)
        panel <- LETTERS[(j - 1L) * length(species) + i]
        usr <- par("usr")
        text(usr[1] + 0.025 * diff(usr[1:2]),
             usr[4] - 0.025 * diff(usr[3:4]), paste0("(", panel, ")"),
             adj = c(0, 1), cex = 1, col = "black")
        if (i == 1L && j == 1L && !tensile) {
          legend("topright", c("Adaxial", "Abaxial"), pch = c(21, 22),
                 pt.bg = adjustcolor(c(7, 6), alpha.f = 0.5), col = c(7, 6),
                 pt.cex = 0.9, cex = 0.95, bg = "white", box.col = "black",
                 text.col = "black")
        }
        # Store physical plot rectangles for layout checks.
        plot_regions[[length(plot_regions) + 1L]] <- c(
          row = i, column = j,
          width = par("pin")[1], height = par("pin")[2],
          left = grconvertX(usr[1], "user", "ndc"),
          top = grconvertY(usr[4], "user", "ndc"))
      }
    }
    # One shared y label per column, and species names above the first column.
    layout(1)
    par(fig = c(0, 1, 0, 1), mar = rep(0, 4), oma = rep(0, 4),
        pty = "m", plt = c(0, 1, 0, 1), new = TRUE)
    plot.new()
    plot.window(xlim = c(0, 1), ylim = c(0, 1), xaxs = "i", yaxs = "i")
    for (j in seq_along(metrics)) {
      text((j - 1L) / length(metrics) + label_offsets[j], 0.5,
           labels[[j]], srt = 90, cex = 1, col = "black")
    }
    for (i in seq_along(species)) {
      region <- plot_regions[[i]]
      text(region["left"], region["top"] + 0.008,
           names(species)[i], adj = c(0, 0), font = 3, cex = 0.9,
           col = "black", xpd = NA)
    }
    text(0.5, 0.006, "Relative water content (%)", adj = c(0.5, 0), col = "black")
    attr(results, "plot_regions") <- do.call(rbind, plot_regions)
    invisible(results)
  }
  results <- draw()
  png_results <- save_submission_png(file, width_mm / 25.4, height_mm / 25.4, 9, draw)
  attr(results, "png_plot_regions") <- attr(png_results, "plot_regions")
  invisible(results)
}

plot_submission_comparison <- function(comparison, file) {
  data <- comparison$data
  cairo_pdf(file, width = 120 / 25.4, height = 120 / 25.4,
            family = "Arial", pointsize = 9, bg = "white")
  on.exit(dev.off(), add = TRUE)
  draw <- function() {
    par(mar = c(4, 4, 1, 1), mgp = c(2.5, 0.6, 0), cex = 1)
    # Include negative decreases (predicted stiffness increases) in the plot.
    plot_limits <- range(c(0, 100, unlist(data[, c(
      "drop_tensile", "drop_adaxial", "drop_abaxial")])), na.rm = TRUE)
    plot(data$drop_tensile, data$drop_adaxial, type = "n", asp = 1,
         xlim = plot_limits, ylim = plot_limits,
         xlab = "Tensile stiffness decrease (%)",
         ylab = "Bending stiffness decrease (%)")
    abline(0, 1, lty = 2)
    for (side in c("adaxial", "abaxial")) {
      colour <- if (side == "adaxial") 7 else 6
      points(data$drop_tensile, data[[paste0("drop_", side)]],
             pch = if (side == "adaxial") 21 else 22, cex = 1.2,
             bg = adjustcolor(colour, alpha.f = 0.5),
             col = adjustcolor(colour, alpha.f = 0.9))
      abline(comparison[[side]], col = adjustcolor(colour, alpha.f = 0.9), lwd = 1.5)
    }
    legend("topleft", c("Adaxial", "Abaxial"), pch = c(21, 22),
           pt.bg = adjustcolor(c(7, 6), alpha.f = 0.5), col = c(7, 6),
           cex = 0.95, bty = "n")
    annotation <- vapply(c("adaxial", "abaxial"), function(side) {
      model <- comparison[[side]]
      statistics <- summary(model)
      sprintf("%s: y = %.3fx %+.3f; R\u00b2 = %.3f; p = %.4f",
              side, coef(model)[2], coef(model)[1], statistics$r.squared,
              coef(statistics)[2, 4])
    }, character(1))
    legend("bottomright", annotation, text.col = c(7, 6), cex = 0.9, bty = "n")
  }
  draw()
  save_submission_png(file, 120 / 25.4, 120 / 25.4, 9, draw)
}

The code below generates a vector PDF for journal submission and a 600 dpi PNG
for preview or preprint preparation, for each manuscript figure. Expand **Show generation code** to inspect each step. The PDFs use the same inputs, exclusions, GAMs, and
prediction grids as the analysis chapters; only the panel layout and typography
change. Figure S1 uses the fixed examples and baseline correction from its
reproduction chapter. Both formats are downloadable rather than embedded on this page.

[Download the generation notebook (QMD)](../outputs/figures/submission/generate_figures.qmd){download="generate_figures.qmd"}

The original layout is retained: six species rows, traits in columns, and square
plotting regions. Figures 1, 2, and 3 are 120, 155, and 85.5 mm wide, respectively.
Their heights are calculated from the panel widths and margins (approximately
235, 228, and 231 mm). Using a figure-specific width within the journal's 178 mm
limit avoids excessively tall figures without rearranging panels. Panel letters
and the association between species, traits, and fitted curves are unchanged.
Species names are italic, and y labels are shared within each trait column.
Figure S2 retains its 120 × 120 mm plot with regression annotations inside it.
All figures use Arial at a 9 pt base size, 8.55 pt tick labels/legends, and 8.1 pt
species names and compact regression annotations. The PDFs retain vector lines
and text. Corrected $E_t A$ values and units are retained.

For journal submission, keep the main text in a DOCX/ODT file without the figure
images, retain the figure legends at the end of that file, and submit each main
figure as an individual PDF. Separate files are also allowed at initial submission.
Supporting information follows its own instructions; the journal recommends a
combined PDF with its figures, legends, tables, title, and authors where possible.

For a preview or preprint version, insert the PNGs using **Insert → Pictures**,
keep the aspect ratio, and disable Word image compression. The PNGs contain
600 pixels per inch at the intended dimensions. Reduce them if necessary to leave
room for captions; enlarging them lowers the effective resolution. Export the
figure-containing document to PDF as needed for the selected preprint service.

PDF lines and text remain vector objects, so increasing the page size does not
add detail. We use the intended manuscript dimensions for both output formats,
without a PDF enlargement step or additional output dependencies. Final printed
width and lettering still matter: the journal specifies widths up to 178 mm and
lettering of 8–12 pt. Check the figures at their intended printed dimensions
before submission. See the
[journal guidelines](https://physiologiaplantarum.org/instructions-for-manuscrip/).

Tensile stiffness is calculated as `E_t * A`, with `A = thick * width.x` from
the instrument dimensions (mm) associated with `E.x` (MPa). The resulting
`EA` is in N; bending-to-tensile stiffness ratios are in mm².

元のレイアウト（6種の行、形質の列、正方形の描画領域）を維持します。図1・2・3の幅はそれぞれ120、155、85.5 mmです。高さは正方形のパネル幅と余白から計算し、それぞれ約235、228、231 mmになります。178 mmを上限として図ごとに幅を調整することで、パネルを並べ替えずに過度な縦長を避けます。パネル文字と、種・形質・推定曲線の対応も維持しています。種名は斜体、縦軸ラベルは形質の列ごとに共通です。図S2は120 × 120 mmで、回帰式と統計量を元と同じ図内に配置します。文字はArialの9 ptを基準とし、目盛数字や凡例には8.55 pt、斜体の種名と回帰式の説明には8.1 ptを使います。PDF内の線と文字はベクター形式です。修正後の $E_t A$ の値と単位を維持しています。

雑誌への提出時は、本文のDOCX/ODTには図の画像を入れず、図の説明文を本文末尾に残し、主図を1図ずつPDFで提出します。初回投稿でも別ファイル提出が認められています。補足資料は別の規定に従い、可能であれば図・説明文・表・論文タイトル・著者名を含む単一PDFにまとめます。

自身のプレビューやプレプリント用には、別の原稿にPNGを**［挿入］→［画像］**から挿入します。縦横比を固定し、Wordの画像圧縮を無効にしてください。PNGは上記の実寸で600 dpiです。図の説明文を収めるための縮小は可能ですが、拡大すると実効解像度が下がります。必要に応じて、図入り原稿を利用するプレプリントサービスに合ったPDFへ書き出します。

PDF内の線と文字はベクターなので、ページを大きくしても細部の情報量は増えません。PDFもPNGも原稿内の配置寸法で作成し、PDFの拡大処理や追加の出力用依存関係は使いません。ただし、最終掲載時の幅と文字サイズは重要です。規定では最大幅178 mm、文字8～12 ptが指定されています。提出前には、上記の実寸で文字・点・線の読みやすさを確認してください。[公式投稿規定](https://physiologiaplantarum.org/instructions-for-manuscrip/)を参照してください。

引張剛性は `E_t * A` として計算します。`A = thick * width.x` は、`E.x`（MPa）に対応する試験機の寸法（mm）から得ます。`EA` の単位はN、曲げ剛性と引張剛性の比の単位はmm²です。

ratios <- merge(
  bending[, c("spp", "leaf_side", "ID", "EI", "E.x", "water_content")],
  tensile[, c("spp", "ID1", "EA", "E.x", "water_content")],
  all = TRUE, suffixes = c("_bending", "_tensile"),
  by.x = c("spp", "ID"), by.y = c("spp", "ID1"))
ratios <- ratios[ratios$water_content_bending >= 60 &
                   ratios$water_content_tensile >= 60, ]
ratios$RWC_mean <- (ratios$water_content_bending + ratios$water_content_tensile) / 2
ratios$stiffness_ratio <- ratios$EI / ratios$EA * 1000
ratios$E_ratio <- ratios$E.x_bending / ratios$E.x_tensile

  ratios, species, metrics = c("stiffness_ratio", "E_ratio"),
