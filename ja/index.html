概要

作者

Kaede Konrai

ノート言語 / Language

Read this page in English (EN)

葉が水を失うと、葉の力学特性はどのように変わるのでしょうか。このサイトでは、6種を対象とした3点曲げ試験と引張試験について、試験機の出力と試料情報の統合から論文用の図の作成までを示します。

ノート解析サイトの草稿

定量解析の再現確認は実施済みですが、論文中の記載には引き続き確認が必要な項目があります。解析に関する注記を参照してください。論文の引用情報、公開データセットのDOI、ライセンスは公開前に追加する予定です。

解析の流れ

  1. 測定データの統合：試験機の出力と試料情報を結合し、除外対象の記録を取り除きます。
  2. 種ごとの形質の要約：葉厚、葉の乾物含有率（LDMC）、単位葉面積当たりの乾燥質量（LMA）をまとめます。
  3. 相対含水率（RWC）の低下に伴う曲げ特性、引張特性、および両者の比を確認します。
  4. RWC 100%から80%までの剛性低下の比較を行います（論文の図S2）。

主要図1～3と補足解析の比較では、RWC 60%以上を用います。モデルは一般化加法モデル（GAM）で、制限付き最尤法（REML）により推定します。

結果の再現方法

入力データは、CP932形式の試験機CSV 56ファイルと、試料情報・除外記録のCSV 3ファイルです。リポジトリの .Renviron で、raw/ と manual/ を含むフォルダーを PROJECT_DATA_DIR に指定してください。Rを再起動し、renv::restore() でパッケージを復元してから、リポジトリのルートで quarto render を実行します。

最初のノートブックが統合済みテーブルを作成し、以降のノートブックがそれを読み込み、図を outputs/figures/ に出力します。元の入力ファイルは変更しません。環境設定と必要なデータの詳細はリポジトリのREADMEを参照してください。

英語版と日本語版をまとめて作成する場合は、PowerShellで ./scripts/render-bilingual.ps1 を実行します。日本語版のみの作成には quarto render --profile ja を使います。

このサイトの範囲

主要な定量解析と剛性低下の比較を収録しています。代表的な荷重–変位曲線（S1）と顕微鏡画像（S3）は、まだノートブックから生成していません。生データと作業中の原稿はサイトに含めていません。

How do leaf mechanical properties change as leaves lose water? These notebooks
follow three-point bending and tensile tests in six species, from instrument
exports and sample measurements to the manuscript figures.

::: {.callout-note title="Draft analysis site"}
The quantitative analysis has been reproduced. Some manuscript reporting
details remain under review; see [Analysis notes](notebook/07-analysis-notes.qmd).
The manuscript citation, public dataset DOI, and licenses will be added before
release.
:::

## Follow the analysis

1. [Integrate the measurements](notebook/01-data-integration.qmd): combine the
   instrument exports with sample information and apply record exclusions.
2. [Summarize the species](notebook/02-species-summary.qmd): leaf thickness,
   leaf dry matter content (LDMC), and leaf mass per area (LMA).
3. Inspect [bending properties](notebook/03-bending.qmd),
   [tensile properties](notebook/04-tensile.qmd), and their
   [ratios](notebook/05-bending-tensile-ratios.qmd) as relative water content
   (RWC) decreases.
4. [Compare stiffness changes](notebook/06-stiffness-comparison.qmd) between
   100% and 80% RWC (manuscript Figure S2).

Figures 1–3 and the supplementary comparison use RWC of at least 60%.
Models are generalized additive
models (GAMs) fitted by restricted maximum likelihood (REML).

## Reproduce the results

The data package contains 56 CP932 instrument CSV files and three metadata or
exclusion CSV files. In the repository's `.Renviron`, set `PROJECT_DATA_DIR`
to the folder containing `raw/` and `manual/`. Restart R, restore the packages
with `renv::restore()`, and run `quarto render` from the repository root.

The first notebook generates the integrated tables; later notebooks read those
tables and write their figures to `outputs/figures/`. Original inputs are not
modified. See the [repository README](https://github.com/maple60/leaf-mechanics-dehydration)
for environment setup and data requirements.

## Scope

This site contains the main quantitative analyses and the stiffness comparison.
Representative force–displacement examples (S1) and microscopy panels (S3) are
not yet generated by the notebooks. Raw data and working manuscript files are
not embedded in the site.
