Reproduction checks

These checks describe the migrated legacy analysis before the tensile stiffness correction below. They do not imply that the corrected Figures 2, 3, and S2 match the legacy curves.

The original GitHub analysis at commit 606501e6a66bde009e91a9326a1c216c9e6e16d1 was compared with the migrated code and the notebook conversion using R 4.5.3, mgcv 1.9-3, Matrix 1.7-3, nlme 3.1-168, and lattice 0.22-7. The four analysis packages match renv.lock; R itself differs from the lockfile’s 4.5.1.

  • Integrated data matched: 496 bending records and 262 tensile records.
  • All 102 GAM calls matched in coefficients, smoothing parameters, model data, predictions, standard errors, and confidence intervals.
  • All 58 SVG outputs matched before notebook rendering. The supplementary comparison was renamed from the source code’s S3 to the manuscript’s S2.

The manuscript’s main figure images span RWC 100–60%, matching this analysis. An older Dropbox code version used 50% and produces different model predictions. The assembled manuscript images have not been checked for pixel equivalence.

Legacy reporting details to reconcile

The S2 values in this table refer to the legacy tensile EI calculation.

Item Manuscript text Recalculation
Aucuba japonica thickness SD 0.001 mm 0.0104403 mm
S2 abaxial regression slope 1.05 1.0514683
S2 abaxial R² 0.97 0.9765379 (adjusted R² ≈ 0.9687)
S2 abaxial p <0.001 0.0015361

The other species’ thickness summaries and all LMA/LDMC mean and SD values agree at the manuscript’s reported precision. Table 1’s sample-count definition remains unresolved: the notebook’s summary counts are nonmissing measurement records for each trait, not confirmed counts of independent leaves.

Inherited exclusions

Tensile stiffness definition

The legacy Figure 2 code used the tensile metadata EI column, matching E.x * I for 248 of 262 records (relative tolerance 10⁻⁶). Figures 2, 3, and S2 now use EA = E.x * thick * width.x, consistent with the manuscript definition of tensile stiffness. Dimensions are from the instrument export, paired with its Young’s modulus, rather than the separate metadata dimensions (two thickness and four width values differ). Figure 2 uses N; the stiffness ratio in Figure 3 uses 10⁻³ mm². Exclusions, matching, and GAM settings are unchanged. S2 now uses RWC ≥60%, matching Figures 1–3, instead of the inherited 50% cutoff. The legacy S2 regression values above must be replaced by the corrected results shown in the stiffness comparison chapter.

With EA and RWC ≥60%, the abaxial S2 regression (five species) has slope 1.138343, intercept 0.8150808, R² 0.9238091, and p = 0.0091385. The adaxial regression (six species) has slope 0.6236132, intercept -3.468724, R² 0.6276111, and p = 0.0602741. These p-values test whether the species-level regression slope is zero. The manuscript’s quoted regression values need updating.

The integration notebook applies exclude_records_bending.csv to both bending and tensile records. It also retains the existing hard-coded tensile exclusions and instrument failure filtering. No exclusion rule was changed during migration.

The supplementary analysis sets the abaxial stiffness decrease for Ligustrum lucidum to missing. Its regression therefore uses five species, compared with six on the adaxial side. The reason for that exclusion should be documented before release.

## 再現性の確認

ここで示す確認結果は、下記の引張剛性の修正前に行った、移行後の従来解析についてのものです。修正後の図2、3、S2が従来の曲線と一致することを示すものではありません。

GitHub上の元の解析（コミット `606501e6a66bde009e91a9326a1c216c9e6e16d1`）を、移行後のコードおよびノートブック版と比較しました。使用環境はR 4.5.3、mgcv 1.9-3、Matrix 1.7-3、nlme 3.1-168、lattice 0.22-7です。4つの解析用パッケージは `renv.lock` と一致しますが、R本体はロックファイルの4.5.1とは異なります。

- 統合済みデータは一致しました（曲げ496件、引張262件）。
- 102回すべてのGAM呼び出しで、係数、平滑化パラメーター、モデルに使うデータ、予測値、標準誤差、信頼区間が一致しました。
- ノートブックのレンダリング前のSVG出力58ファイルがすべて一致しました。補足比較図の名称は、元のコードのS3から論文のS2へ変更しています。

論文の主要図の範囲はRWC 100～60%で、この解析と一致します。Dropbox内の古いコードは50%以上を使うため、モデルの予測値が異なります。組み上げた論文の図について、画素単位の一致は確認していません。

## 従来の記載との照合が必要な項目

次の表のS2の値は、従来の引張 `EI` による計算結果です。

| 項目 | 論文の記載 | 再計算 |
| --- | --- | --- |
| *Aucuba japonica* の葉厚の標準偏差 | 0.001 mm | 0.0104403 mm |
| S2の背軸側の回帰直線の傾き | 1.05 | 1.0514683 |
| S2の背軸側のR² | 0.97 | 0.9765379（自由度調整済みR² ≈ 0.9687） |
| S2の背軸側のp値 | <0.001 | 0.0015361 |

他の種の葉厚の要約値、およびLMA・LDMCの平均と標準偏差は、論文の表示精度で一致しています。表1のサンプル数の定義は未解決です。ノートブックの要約に示す数は、形質ごとの欠測を除いた測定記録数であり、独立した葉の枚数としては未確認です。

## 元の解析から引き継いだ除外処理

### 引張剛性の定義

従来の図2のコードは、引張試験の試料情報にある `EI` 列を使っていました。この値は262件中248件で `E.x * I` と一致します（相対許容誤差10⁻⁶）。現在の図2、3、S2は、論文の引張剛性の定義に合わせて `EA = E.x * thick * width.x` を使います。寸法には別途の試料情報ではなく、ヤング率に対応する試験機の出力値を使います（両者で葉厚2件、幅4件が異なります）。図2の単位はN、図3の剛性比は10⁻³ mm²です。除外、対応付け、GAM設定は変更していません。S2のRWC下限は従来の50%から60%に変更し、図1～3と統一しています。上表の従来のS2回帰値は、剛性比較の章に示す修正後の結果に更新する必要があります。

`EA` とRWC 60%以上のデータを用いたS2の背軸側の回帰（5種）は、傾き1.138343、切片0.8150808、R² 0.9238091、p = 0.0091385です。向軸側の回帰（6種）は、傾き0.6236132、切片-3.468724、R² 0.6276111、p = 0.0602741です。このp値は種間回帰の傾きがゼロかを検定しています。論文中の回帰値を更新する必要があります。

統合用ノートブックでは、`exclude_records_bending.csv` を曲げ・引張の両方に適用しています。コード内で指定されている引張試験の除外と、試験機の失敗記録の除外も維持しています。移行時に除外規則は変更していません。

補足解析では、*Ligustrum lucidum* の背軸側の剛性低下を欠測扱いにしています。そのため、回帰に用いる種数は向軸側の6種に対して背軸側は5種です。この除外理由は公開前に記載する必要があります。
