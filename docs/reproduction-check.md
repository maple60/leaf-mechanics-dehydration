## 原稿との未解決の相違

1. **アオキの厚さの標準偏差**：表1は `0.001 mm`、既存の形質要約コードによる
   再計算は `0.0104403 mm`（小数点以下3桁なら `0.010 mm`）。平均値は一致する。
   そのほかの5種の厚さと、全6種の LMA・LDMC の平均・標準偏差は掲載桁で一致する。
2. **表1の n**：原稿の種別 n は、現行の処理済みデータ行数や LMA に利用した
   行数と一致しない。独立試料数・試験数・除外条件など、n の集計定義を確認する必要がある。
3. **剛性低下の回帰**：原稿の abaxial 側は傾き1.05、R²=0.97、p<0.001。
   再計算は n=5、傾き `1.0514683`、R²=`0.9765379`、p=`0.0015361`。
   傾きは一致するが、p<0.001 は再現しない。調整済み R² は約0.9687なので、
   原稿の R² が調整済みを指すか確認が必要。通常の R² を2桁に丸めると0.98になる。
4. **補足図番号**：`scripts/07_fig_S3.qmd` の剛性低下比較は、原稿の **Fig. S2**。
   原稿の **Fig. S3** は顕微鏡写真。番号・ファイル名はまだ変更していない。
5. **補足図の範囲**：原稿の S1（代表荷重–変位曲線）の完成した生成コードと、
   S3（顕微鏡写真）の組版は現行リポジトリにない。したがって、論文の全図が
   現行コードだけで再生成できる、という状態ではない。
