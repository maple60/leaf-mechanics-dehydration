Changes in leaf mechanical properties under bending and tensile tests during dehydration in six plant species

Author

Kaede Konrai

NoteLanguage / 言語

日本語はこちら（JP）

How do leaf mechanical properties change as leaves lose water? These notebooks follow three-point bending and tensile tests in six species, from instrument exports and sample measurements to the manuscript figures.

NoteDraft analysis site

The quantitative analysis has been reproduced. Some manuscript reporting details remain under review; see Analysis notes. The manuscript citation, public dataset DOI, and licenses will be added before release.

Follow the analysis

  1. Integrate the measurements: combine the instrument exports with sample information and apply record exclusions.
  2. Summarize the species: leaf thickness, leaf dry matter content (LDMC), and leaf mass per area (LMA).
  3. Inspect bending properties, tensile properties, and their ratios as relative water content (RWC) decreases.
  4. Compare stiffness changes between 100% and 80% RWC (manuscript Figure S2).

Figures 1–3 and the supplementary comparison use RWC of at least 60%. Models are generalized additive models (GAMs) fitted by restricted maximum likelihood (REML).

Reproduce the results

The data package contains 56 CP932 instrument CSV files and three metadata or exclusion CSV files. In the repository’s .Renviron, set PROJECT_DATA_DIR to the folder containing raw/ and manual/. Restart R, restore the packages with renv::restore(), and run quarto render from the repository root.

The first notebook generates the integrated tables; later notebooks read those tables and write their figures to outputs/figures/. Original inputs are not modified. See the repository README for environment setup and data requirements.

Scope

This site contains the main quantitative analyses and the stiffness comparison. Representative force–displacement examples (S1) and microscopy panels (S3) are not yet generated by the notebooks. Raw data and working manuscript files are not embedded in the site.

## 解析の流れ

1. [測定データの統合](notebook/01-data-integration.qmd)：試験機の出力と試料情報を結合し、除外対象の記録を取り除きます。
2. [種ごとの形質の要約](notebook/02-species-summary.qmd)：葉厚、葉の乾物含有率（LDMC）、単位葉面積当たりの乾燥質量（LMA）をまとめます。
3. 相対含水率（RWC）の低下に伴う[曲げ特性](notebook/03-bending.qmd)、[引張特性](notebook/04-tensile.qmd)、および[両者の比](notebook/05-bending-tensile-ratios.qmd)を確認します。
4. RWC 100%から80%までの[剛性低下の比較](notebook/06-stiffness-comparison.qmd)を行います（論文の図S2）。

主要図1～3と補足解析の比較では、RWC 60%以上を用います。モデルは一般化加法モデル（GAM）で、制限付き最尤法（REML）により推定します。

## 結果の再現方法

入力データは、CP932形式の試験機CSV 56ファイルと、試料情報・除外記録のCSV 3ファイルです。リポジトリの `.Renviron` で、`raw/` と `manual/` を含むフォルダーを `PROJECT_DATA_DIR` に指定してください。Rを再起動し、`renv::restore()` でパッケージを復元してから、リポジトリのルートで `quarto render` を実行します。

最初のノートブックが統合済みテーブルを作成し、以降のノートブックがそれを読み込み、図を `outputs/figures/` に出力します。元の入力ファイルは変更しません。環境設定と必要なデータの詳細は[リポジトリのREADME](https://github.com/maple60/leaf-mechanics-dehydration)を参照してください。

`quarto render` は英語版と日本語版をまとめて作成します。日本語版のみの作成には `quarto render --profile ja` を使います。
